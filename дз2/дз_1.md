# Домашнее задание 1

Для заданий нужен личный ключ. Впишите его в `.env`, как описано в README.

## 1. Замер на своём ключе

Запустите по очереди:

```bash
python 1_raw_request.py
python 3_prefix_cache.py
python -m desk.bench --n 5
python -m desk.bench --n 30
```

По выводу заполните отчёт `отчёт_1.md` по шаблону `выбор_шаблон.md`.
Каждое утверждение в отчёте подкрепите числом из своего замера.

## 2. Кандидат с примерами

Добавьте в `CANDIDATES` в `desk/bench.py` четвёртого кандидата: постановку
`DETAILED` и два разобранных обращения. Обращения придумайте сами, не берите
из `tickets.jsonl`. Прогоните кандидата на тех же 30 обращениях с `--only`.
Как изменились точность и число входных токенов? Ответ допишите в отчёт.

## 3. Цена ошибок

Неверно отнесённое обращение отнимает у оператора две минуты, минута
оператора стоит 10 условных единиц. Посчитайте стоимость месяца при 50 000
обращений в день для каждого кандидата вместе с ошибками. Меняется ли выбор?
Ответ допишите в отчёт.

## 4. Со звёздочкой

Запустите замер короткой постановки три раза подряд с
`--only "короткая постановка"`. Насколько меняется точность от запуска к
запуску? Что это значит, если сравнивать кандидатов по одному запуску?

Всё задание тратит около 50 тысяч взвешенных токенов, дневного лимита ключа
хватает с запасом.

Сделайте форк этого репозитория, закоммитьте в него `отчёт_1.md` и изменения
в `desk/bench.py` и пришлите ссылку на форк в Telegram: @pashaanik. Файл
`.env` с ключом не коммитьте, он уже в `.gitignore`.
